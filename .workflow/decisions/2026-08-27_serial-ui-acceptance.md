# 2026-08-27 串口调试 UI 验收记录 + 自动化测试经验

## 验收结论：通过 ✅

- **布局**：VOFA+ 风格（左设置栏 + 右数据区/发送区 + 底部状态栏），明/暗主题截图各 1 张，语义色自适应正常，无硬编码样式。
- **功能实测**（COM20↔COM21 ELTIMA 虚拟串口对，对端 pyserial 回显进程）：
  - `[TX] ToolHub UI 验收测试 ABC-123`（31B 1 包）→ 对端收到后回发 → `[RX] ECHO:ToolHub UI 验收测试 ABC-123`（36B 1 包），往返 101ms。
  - 端口列表加载、参数配置、时间戳、收发方向标识、包/字节/速率统计全部正确。
- **验证中发现并修复**：
  1. `@Slot()` 未标 `result=list` 导致 QML 拿到的返回值是 undefined → 端口列表为空。
  2. 可编辑 ComboBox 手输后 `currentText` 为空 → `currentDevice()` 改用 `editText` 兜底。
  3. 波特率默认值用 `editText` 会被模型重置 → 改用 `currentIndex: 4`。
- **遗留观察**：多个应用同时打开同一 ELTIMA 虚拟口会互相抢占/回声循环（曾出现 RX 洪泛），属环境干扰非程序缺陷；实测时保证对端进程唯一即可。

## 自动化 GUI 测试经验（写给后续会话）

1. **锁屏会阻断一切屏幕操作**：Windows 锁屏切到安全桌面 → 全屏截图报 unsupported、坐标点击因窗口身份校验失败被拒、截图帧频繁过期。元素点击（AXPress）不受影响。**先确认屏幕未锁再走截图验收。**
2. **优先元素点击**：QML 应用解锁后 UIA 树完整（按钮/输入框带名称），`set_value` 可直接写 FluTextBox/ComboBox 编辑框，最可靠。
3. **帧过期重试模式**：全屏帧被后台窗口动画弄过期时，改用 `get_app_state(include_screenshot=true)` 的窗口级帧，捕获后立即提交点击。
4. **后台进程验证优先**：串口 I/O 的正确性先用纯 Python 脚本回环验证（不等 UI），UI 层只验交互与渲染。
