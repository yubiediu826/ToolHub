# 设计原则（design-principles）

1. **FluentUI-first**：任何 UI 需求先查组件目录（`docs/fluentui-component-map.md`）；有现成 `Flu*` 组件绝不自绘；没有则按 ui-design-spec 第 6 节自绘并登记。
2. **单一数据源（SSOT）**：组件清单、样式规范、协议预设各只有一份文档；代码与文档不同步时以修复同步为提交前提。
3. **渐进式交付**：每阶段产出可运行、可验收的版本；不追求一次做完三个工具。
4. **规范随反馈演进**：用户的 UI 反馈落实后必须回写 ui-design-spec（写入对应小节或新增决策），保证下次开发有据可依。
5. **配置外置**：协议定义、串口参数等用户数据全部 JSON 持久化，与代码分离。
6. **参考先行**：串口调试参考 SerialTool-comm-v1.7.4 的终端功能（仅收发+日志），协议解析参考 BMS/EMS 上位机的帧格式与卡片布局，UI 风格以 FluentUI/WinUI 为准而非参考项目的 WinForms 风格。
